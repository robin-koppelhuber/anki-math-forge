{# The complete state machine, derived from the code rather than from memory. Four things it is easy to get wrong here, all of them checked against the source: * `Ledger.set_state` permits any unit state to any other and the triage view binds q/s/u unconditionally, so `u` is not "undo a skip" -- it returns *any* unit to new, a carded one included. * `Ledger.suggest` accepts any member of STATES and `accept()` applies whatever was proposed. A suggestion is not a proposed *skip*; skipping is merely what `classify` happens to propose today. * Only an *approved* card is demoted by an edit (`Card.effective_status`). A draft edited stays a draft, so a card can be revised any number of times before anyone approves it. * An annotation is not a state and does not attach to a particular box. It can sit on any unit or any card, from either side, and it blocks sync wherever it sits -- which is why the only arrow it gets is the one to the sync gate. Arrows to individual boxes would claim something untrue. Geometry is checked by tests/test_fsm.py: no overlapping boxes, no edge through a box, no overlapping labels. Hand-authored SVG does not stay correct on its own. #}
