{# The complete state machine, derived from the code rather than from memory. Five things it is easy to get wrong here, all of them checked against the source: * `carded` and `draft` are **one moment**, not two steps. `/extract-cards` writes the card file and marks the unit carded in the same breath; there is no state where one has happened and the other has not. The diagram used to run them as a long arrow from the top-right of one lane to the bottom-left of the other, which reads as a journey. It is a *split*: from here on there are two objects, and the rest of the machine is about the second one. * `Ledger.set_state` permits any unit state to any other and the triage view binds q/s/u unconditionally, so `u` is not "undo a skip" -- it returns *any* unit to new, a carded one included. * `Ledger.suggest` accepts any member of STATES and `accept()` applies whatever was proposed. A suggestion is not a proposed *skip*; skipping is merely what `classify` happens to propose today. * Only an *approved* card is demoted by an edit (`Card.effective_status`). A draft edited stays a draft, so a card can be revised any number of times before anyone approves it. * An annotation is not a state and does not attach to a particular box. It can sit on any unit or any card, from either side, and it blocks sync wherever it sits -- which is why the only arrow it gets is the one to the sync gate. Arrows to individual boxes would claim something untrue. The assistive passes are drawn the same way as each other, each under the state it acts on: `/transcribe` fills in what a unit says, `/gist` what a card from it would be about, `/augment` what a card is missing. None of them moves anything, which is why all three are boxes hanging off a state rather than arrows between states. `/gist` especially: nothing downstream even reads it, so an arrow out of it would claim something untrue. Geometry is checked by tests/test_fsm.py: no overlapping boxes, no edge through a box, no overlapping labels. Hand-authored SVG does not stay correct on its own. #}
